- ログイン画面　/login
    
    !ログイン画面.png

    - 補足（資料にない仕様）
        - ログイン済みで利用者がDBに存在する場合は `/` に移動する。
        - ID・パスワードの形式は登録時と同じ。空欄や形式違反は該当欄に表示し、認証しない。
        - 未登録IDと誤パスワードはどちらも「ユーザーIDまたはパスワードが違います」と表示する。
        - DB障害などは「ログインできませんでした。時間をおいて再度お試しください」と表示する。
        - 失敗時はIDだけを残し、パスワードは空にする。ログイン成功・失敗の3秒ポップアップは出さない。
        - 送信中はボタンを「ログイン中…」にして無効化する。幅375pxではロゴを非表示にする。

    - 「♡」はいいね。投稿者など相手からも見える反応。

    - いいねとお気に入りは別のデータ・操作として扱う。

- メイン画面 / /?follow=true
    
    !メイン画面.png

    - 補足（資料にない仕様）
        - `/` は全利用者の投稿・リツイート、`/?follow=true` はフォロー中のユーザーが行った投稿・リツイートだけを新しい順に表示する（自分の投稿・リツイートは含めない）。該当がなければ「フォロー中のユーザーの投稿はまだありません」と表示する。
        - リツイートはリツイートした日時で並べ、絞り込みはリツイートした人のフォロー関係で判定する。カードには「○○さんがリツイート」と元の投稿者・本文を表示する。
        - フォローの絞り込みはログインが必要。未ログインで `/?follow=true` を開くと `/login` へ移動する。
        - 1ページ20件。「次の20件」で過去へ進み、「最新に戻る」で先頭に戻る。フォローの切り替えでは先頭に戻る。
        - 日時は `YYYY/MM/DD HH:mm`（日本時間）で表示する。
        - 現時点ではテキストの表示まで。投稿・お気に入り・リツイート・フォローの操作、画像、プロフィール等のナビ項目は、それぞれの機能の実装時に追加する。
    
- プロフィール画面 /profile/{ユーザーID}
    
    !プロフィール画面(自分).png
    
    !プロフィール画面(他人).png

    - 補足（資料にない仕様）
        - 未ログインでも閲覧できる。ユーザーIDは大文字小文字を区別せずに検索し、表示とリンクには登録時の表記を使う。
        - 自分のプロフィールには「自分のプロフィール」を表示する。他人のプロフィールには「フォローする／フォロー解除」のボタンを表示する（下記）。
        - `?tab=retweets` は本人が実行したリツイート、`?tab=following` は本人がフォローしている人、`?tab=followers` は本人をフォローしている人。投稿タブ（tabなし）は本人の通常投稿だけ。
        - 件数（○ フォロー／○ フォロワー）から一覧へ移動できる。どの一覧も20件ずつで、「次の20件」「最新に戻る」で移動する。
        - 利用開始日は `YYYY年MM月DD日から利用しています`（日本時間）。
        - 未登録・形式違反のIDは「このユーザーは見つかりませんでした」。取得障害とは区別する。
        - 「ツイート」「リツイート」「いいね」のタブを出す。`?tab=likes` はその利用者がいいねした投稿の公開一覧で、未ログイン・他人からも閲覧できる（いいねした日時の新しい順に20件ずつ）。いいねがなければ「いいねした投稿はまだありません」。
    
- プロフィール編集画面 /profile/{ユーザーID}/edit
    
    !プロフィール編集画面.png

    - 補足（資料にない仕様）
        - 機能一覧に合わせ、画面案にない「ユーザーID」欄を追加している（名前・ユーザーID・自己紹介を同じ画面で編集する）。
        - 本人だけが編集できる。自分のプロフィールに「プロフィール編集」リンクを表示する。未ログインは `/login`、他人・古いIDの編集URLは「このユーザーは見つかりませんでした」。
        - 保存すると新しいユーザーIDのプロフィールへ移動し、上部に「プロフィールを更新しました」を3秒表示する。失敗時は画面に留まり、欄ごとのエラーと入力値を表示する。
        - 左上の「×」（編集をキャンセル）は保存せずに編集前のプロフィールへ戻る。
        - ユーザーIDを変更すると旧IDのURLは使えなくなる。ログイン状態はそのまま続き、次回からは新しいIDでログインする（パスワードは変わらない）。
        - 本人が複数のタブから保存した場合は、最後に成功した保存が残る。
        - 画像の変更は対象外。
    
- アカウント削除画面 /profile/{ユーザーID}/delete
    
    !アカウント削除画面.png

    - 補足（資料にない仕様）
        - 本人だけが使える。自分のプロフィールのアカウント操作領域に「アカウント削除」リンクを置く。未ログインは `/login`、他人・古いIDの削除URLは「このユーザーは見つかりませんでした」。
        - 現在のパスワードを入力して削除する。削除は即時で元に戻せない（アカウント・投稿・フォロー関係・本人のリツイート・本人の投稿へのリツイート）。他人のアカウントや投稿は残る。
        - パスワードが違う場合は「パスワードが違います」と表示し、削除もログアウトもしない。「戻る」は何もせずプロフィールへ戻る。
        - 削除後はログアウトしてログイン画面へ移動し、上部に「アカウントを削除しました」を3秒表示する。
        - 削除はできたがログアウト処理に失敗した場合、または削除時点で対象を確認できなかった場合は、ログイン画面に消えない説明を表示する。
    
- ツイート作成画面 ダイアログ
    
    !ツイート作成画面.png

    - 補足（資料にない仕様）
        - 左ナビ（375pxでは上部）の「ツイートする」から開く。未ログインならログイン画面へ移動し、「ツイートするにはログインしてください」を3秒表示する。
        - 本文は280文字以下、画像はJPEG・PNGを1枚5MB以下で4枚まで。本文と画像のどちらかが必要（空白だけの本文は内容なしとみなす）。
        - 本文のEnterは改行。「ツイートする」ボタンで投稿する。閉じる・Escで破棄する（背景クリックでは閉じない）。投稿の確定中は閉じられない。
        - 画像は選んだ順に表示・保存する。プレビューの「削除」で解除、失敗した画像は「再試行」できる。
        - 投稿に成功するとメイン画面の先頭へ移動し「ツイートしました」を3秒表示する。失敗時はダイアログと入力を保ったまま、欄ごとのエラーと「ツイートに失敗しました」を3秒表示する。
        - 動画・投稿の編集削除・画像の並べ替えや拡大表示は対象外。
    
- ツイート編集画面 ダイアログ
    
    !ツイート編集画面.png

    - 補足（資料にない仕様）
        - 元投稿者が自分のカード（メイン・フォローのみ・プロフィールのツイート／リツイート、他人がリツイートしたカードを含む）にだけ「…」（ツイートの操作）を出し、「編集する」で開く。自分がリツイートしただけの他人の投稿は編集できない。削除は下記、報告は実装時に追加する。
        - 開くときにサーバーで所有者を確かめ、DBの現在の本文・画像を初期値にする。未ログインならログイン画面で「ツイートを編集するにはログインしてください」を3秒表示する。
        - 既存画像は解除でき（保存するまで元の投稿は変わらない）、新しい画像を追加できる。保持する既存画像と新規画像で合計4枚まで。並べ替えはできない。
        - 「更新」で保存し、成功すると画面を移動せず（URL・タブ・ページ位置を保ったまま）「ツイートを更新しました」を3秒表示する。投稿日時は変えないので一覧の並びも変わらない。
        - 別の画面で先に更新されていた場合は上書きせず「他の画面で更新されています。閉じて開き直してください」を表示する。失敗時はダイアログと入力を保ち、「ツイートの更新に失敗しました」を3秒表示する。
        - 閉じる・Escは保存せずに閉じる。保存中は閉じられない。

- ツイート削除 確認ダイアログ

    - 補足（資料にない仕様）
        - 編集と同じく、元投稿者の自分のカードの「…」（ツイートの操作）に「削除する」を出す。メニューは上下矢印・Home・Endで移動でき、Tab・Escで閉じる。
        - 「本当に削除しますか？」と「投稿・添付画像・この投稿へのリツイートは元に戻せません」、対象の本文、「はい」「いいえ」を表示する。初期フォーカスは「いいえ」。
        - 「いいえ」・Escは何も変更せずに閉じる。背景クリックでは閉じない。削除中は「はい」「いいえ」・Escを受け付けない。
        - 成功すると画面を移動せず（URL・条件を保ったまま）「ツイートを削除しました」を3秒表示し、同じ投稿のカードとリツイートをすべて消す。最後の投稿を消した場合は空の一覧になる。
        - 既に削除されていた場合は「このツイートは既に削除されています」と通知して閉じる。失敗時は開いたまま理由と「ツイートの削除に失敗しました」を表示し、再試行できる。
        - 開いた後に別の利用者でログインし直していた場合は、どちらの投稿も削除しない。未ログインならログイン画面で「ツイートを削除するにはログインしてください」を3秒表示する。

- 作成・編集・削除ダイアログの通信の失敗（共通）

    - 補足（資料にない仕様）
        - 送信で通信が失敗したら、ダイアログを閉じずに入力（本文・画像・削除の対象）を保ったまま「通信に失敗しました。もう一度お試しください」を3秒表示し、ダイアログ内に「通信に失敗し、処理結果を確認できませんでした。入力を変更せず、もう一度お試しください」を表示する。閉じる・Esc・画像の操作・再試行ができる。
        - 再試行は同じボタンを押したときだけで、同じ下書きのまま送る。先の送信が実は保存されていた場合も、投稿は1件のまま（作成は「ツイートしました」、編集は「ツイートを更新しました」、削除は「このツイートは既に削除されています」）。
        - ダイアログを開く準備で通信が失敗したら開かず、画面上部に「通信に失敗しました。もう一度お試しください」を表示する。もう一度押せば開ける。

- お気に入り一覧 /favorites

    - 補足（資料にない仕様）
        - ログイン中だけ、左ナビ（375pxでは上部）に「お気に入り」を出す。本人だけが見られる一覧で、未ログインで開くとログイン画面へ移動する。
        - 各カードの右端の旗のようなアイコン（お気に入りに追加／お気に入りを解除）で保存・解除する。リツイートのカードで押しても元投稿を保存し、同じ投稿のカードすべてに反映する。未ログインで押すと「ログイン中のみお気に入りに設定できます」を3秒表示し、その場に留まる。
        - 保存した日時の新しい順に20件ずつ表示し、「次の20件」「最新に戻る」で移動する。元投稿の編集は反映され、元投稿の削除・作者の退会で一覧から消える。
        - 一覧で解除した投稿はその場で消える。保存がなければ「お気に入りはまだありません」を表示する。

- いいね（各投稿カードの♡）

    - 補足（資料にない仕様）
        - 未登録は輪郭、登録済みは塗りつぶしのハートと公開件数を、お気に入りの旗より前に表示する。リツイートのカードで押しても元投稿へのいいねになり、同じ投稿のカードすべてに反映する。自分の投稿にもいいねできる。
        - 未ログインで押すと「ログイン中のみいいねできます」を3秒表示し、その場に留まる。失敗時は状態・件数を変えずに理由を3秒表示する。
        - いいねは相手からも見える（件数と、プロフィールの「いいね」タブ）。お気に入りの保存状態・保存一覧は引き続き本人だけが見られる。

- リツイート（各投稿カードの「リツイートする／リツイートを解除」）

    - 補足（資料にない仕様）
        - 状態と公開件数を、いいね・お気に入りの旗より前に表示する。リツイートのカードで押しても元投稿のリツイートになり、同じ投稿のカードすべてに反映する。自分の投稿もリツイートできる（資料に制限がないための補完仕様）。
        - 解除できるのは自分のリツイートだけ。解除すると自分のリツイートのカードは消え、元投稿や他人のリツイートのカードは残る。解除後にもう一度リツイートすると、新しい日時でタイムラインの先頭側に出る。リツイート済みのまま再送しても日時・順位は変わらない。
        - 未ログインで押すと「ログイン中のみリツイートできます」を3秒表示し、その場に留まる。失敗時は状態・件数を変えずに理由を3秒表示する。操作後も表示中のURL・ページ位置を保つ。

- フォロー（他人のプロフィールの「フォローする／フォロー解除」）

    - 補足（資料にない仕様）
        - 自分のプロフィールには出さない。自分自身はフォローできない（サーバーでも拒否する）。
        - 未ログインでもボタンを表示し、押すと「ログイン中のみフォローできます」を3秒表示してその場に留まる。失敗時は状態を変えずに理由を3秒表示する。
        - フォロー済みのまま再送しても関係の日時は変わらない。解除後にもう一度フォローすると、新しい日時で一覧の先頭に出る。相互フォローでき、解除しても相手から自分へのフォローは残る。
        - 成功すると相手のフォロワー数・自分のフォロー数・両側の一覧・「フォローのみ」に反映する。表示中のURL・タブは保つ。
        - フォロー・フォロワー一覧の各行にはボタンを置かず、行から相手のプロフィールへ移動して操作する。


- 通常ログアウト（共通ナビ・自分のプロフィール）

    - 補足（資料にない仕様）
        - PC・375pxの共通ナビと、自分のプロフィールのアカウント操作領域に「ログアウト」を出す。専用画面は作らない。
        - 押すと「ログアウト中…」になり、連打できない。投稿ダイアログの準備中・表示中はログアウトできず、ログアウト中も新しいダイアログを開けない。
        - 成功するとログイン画面へ移り、「ログアウトしました」を3秒表示する。再読み込みでは通知を出さない。本人用の編集・削除・お気に入りなどの表示は消える。
        - 失敗時は画面を移動せず「ログアウトできませんでした。もう一度お試しください」を3秒表示し、再試行できる。別の利用者へ切り替わっていたら、その利用者をログアウトさせずに画面の開き直しを案内する。
        - 投稿や保存、他のブラウザのログインはそのまま残る。
